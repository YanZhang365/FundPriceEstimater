# 基金数据爬取项目

## 项目概述

这是一个自动化基金数据爬取项目，专门用于获取ETF基金和场外基金的实时数据，包括基金净值、涨跌幅、持仓情况等，并将数据通过企业微信发送给用户。项目支持定时执行和手动执行两种模式，适用于 macOS 系统环境。

## 项目架构

项目采用模块化设计，主要包括以下几个部分：

- **核心爬虫模块**：负责从不同数据源获取基金数据
- **工具模块**：提供浏览器驱动、定时任务、企业微信推送等功能
- **持仓管理模块**：管理基金持仓信息
- **配置模块**：统一管理项目配置参数

## 核心模块介绍

### 1. config.py - 项目配置

- **企业微信配置**：包括企业ID、应用ID、密钥等
- **基金配置**：定义ETF基金和场外基金代码列表，按类别组织（科技、医疗、消费、金融银行等）
- **定时配置**：设定自动执行时间
- **环境配置**：浏览器类型、是否开启无头模式等

### 2. main.py - 主入口

- 支持命令行参数解析（单次执行或定时执行）
- 信号处理（捕获Ctrl+C强制退出）
- 腾讯云函数入口支持
- 结合市场数据和基金数据生成图表

### 3. fund_core.py - 基金爬取核心

- 统一协调ETF和场外基金数据抓取
- 实现完整的数据获取流程
- 包含错误处理和日志记录

### 4. get_etf.py - ETF基金数据获取

- 从新浪财经获取ETF基金实时数据
- 计算30天内最高价和最低价的差值百分比
- 实现反爬虫延迟策略

### 5. get_fund_realtime.py - 基金实时数据获取

- 使用Selenium获取基金实时持仓数据
- 从东方财富网获取基金详细信息
- 包含数据验证和异常处理

### 6. get_market_volume.py - 市场成交量数据

- 从腾讯财经和东方财富网获取指数数据
- 获取上证指数和深证成指的实时信息
- 获取特定板块的涨跌幅数据

## 功能特性

### 数据获取功能

- **ETF基金数据**：实时价格、涨跌幅、30天高低价差值
- **场外基金数据**：基金净值、估算涨跌、历史趋势
- **市场数据**：上证指数、深证成指、主要板块涨跌幅

### 自动化功能

- **定时任务**：支持按预设时间自动执行
- **企业微信推送**：将基金数据图表推送到企业微信群
- **图像生成**：将基金数据可视化为图表

### 错误处理

- **多重容错机制**：当实时数据获取失败时，保留基本信息
- **异常捕获**：对各种可能的错误进行处理
- **日志记录**：详细记录执行过程和错误信息

## 技术栈

- **Python**：主要编程语言
- **Selenium**：Web自动化操作
- **AkShare**：金融数据接口
- **Requests**：HTTP请求处理
- **Pandas**：数据处理
- **Matplotlib**：数据可视化
- **企业微信API**：消息推送

## 运行方式

```bash
# 定时模式（默认）
python main.py

# 单次执行模式
python main.py --mode once
```
